# SkillNexis Week 1 - MERN Internship Assignment

This project covers the Week 1 requirements:

- Semantic HTML5 structure
- Responsive CSS with Flexbox and Grid
- JavaScript ES6+ basics
- React components, props, state and events
- Personal portfolio with About, Education, Projects and Contact
- Reusable Header, Footer, Card, Button and Form components
- React Blog UI using local post data
- Search and category filtering
- Responsive navigation

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Build

```bash
npm run build
```
